# Signify

Mission: Signify helps anyone learn ASL with instant feedback from their webcam, using structured learning plans and step-by-step guidance to lead to ASL mastery.
Stack: React + Vite, MediaPipe Hand Landmarker, k-NN for letter recognition, localStorage for progress, Vercel for hosting.
For Contest: Congressional App Challenge. Deadline/Goals: App done by Oct 20, video submitted by Oct 26.
- Design direction: feels friendly, comfortable, and education, no gradients, shouldn't feel like a 2-minute prompted AI-generated website 
-Font: Readex Pro
- Colors: primary #3D5A80, highlight #98C1D9, success #8DB580, hint #BA9593, text #293241, background #F7F9FB, tint #E8F0F6
- rounded corners
- Large action buttons with obvious purpose 
- easy to use website
- Shouldn't make deaf community feel gimmicky in any way
- Project set up, webcam shows on the page, code is on GitHub
- Skeleton hand tracking is done 
- Images from American Society for Deaf Children(Free online, copyright belongs to them) 
- Added first couple of lessons, XP, path map, progress bar, streak, and badges
